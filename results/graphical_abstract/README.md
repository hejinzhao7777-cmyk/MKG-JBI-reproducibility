# Graphical abstract

`Graphical_Abstract.pdf` is the vector submission asset and
`Graphical_Abstract.svg` is the editable web/vector counterpart. Both are
generated by:

```bash
python code/make_cmpb_graphical_abstract.py \
  --output-base results/graphical_abstract/Graphical_Abstract
```

The four panels deliberately match the manuscript's central evidence chain:
candidate relation layers, reliability gating with an explicit reject-all
branch, a frozen compact signature, and outcome-free external scoring.
Exploratory conformal analyses are not shown because they are not a primary
claim of the CMPB submission.
